## Descripción del proyecto
Desarrollo de una interfaz gráfica en **Processing** vinculada de forma bidireccional mediante comunicación serie con un programa en **Arduino** (simulado en SimulIDE). 

El sistema permite:
1. Monitorear en tiempo real el estado lógico (Alto o Bajo) de dos entradas digitales (`E1` y `E2`) accionadas mediante pulsadores.
2. Conmutar el estado de dos salidas digitales (`L1` y `L2`) tanto al presionar los pulsadores físicos/simulados como al hacer clic con el mouse sobre los indicadores correspondientes en la interfaz gráfica.
